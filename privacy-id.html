Kebijakan privasi

Tanggal berlaku: 29 Oktober 2026 · Berlaku untuk Work Camera 0.4.0

Work Camera adalah alat yang berjalan di perangkat Anda: tidak terhubung ke internet, tidak memerlukan akun, dan tidak mengumpulkan informasi pribadi apa pun.

1. Kami tidak mengumpulkan informasi apa pun

Aplikasi ini tidak memiliki server dan tidak memuat iklan, statistik, atau fitur pelacakan. Foto, video, dan data penggunaan Anda tidak pernah dikirim kepada siapa pun. Pengambilan foto dan video, impor, kompresi, pemberian tanda air, dan pengelolaan album hanya dilakukan di perangkat Anda.

2. Penggunaan izin

  • Kamera: Mengambil foto dan video.
  • Mikrofon: Merekam suara video.
  • Foto: Menyimpan, membaca, dan mengelola foto serta video. Konfirmasi Anda selalu diperlukan sebelum file asli dihapus.

Anda dapat menonaktifkan izin kapan saja di pengaturan sistem; fitur terkait kemudian tidak dapat digunakan.

3. Tempat penyimpanan data Anda

Foto dan video disimpan di pustaka foto sistem. Pengelompokan album, masa simpan, dan pengaturan hanya disimpan di perangkat ini. Menghapus instalasi aplikasi akan menghapus catatan lokal ini, tanpa memengaruhi foto dan video di pustaka foto sistem. Sinkronisasi sistem seperti Foto iCloud mengikuti pengaturan sistem Anda.

4. Berbagi

File yang dipilih hanya diserahkan ke aplikasi pilihan Anda saat Anda sendiri membagikannya melalui panel berbagi sistem. Setelah itu, file ditangani oleh aplikasi tersebut.

5. Situs web ini

Situs web ini berupa halaman statis yang dihosting di GitHub Pages, tanpa skrip statistik atau cookie. GitHub dapat mencatat alamat IP pengunjung untuk tujuan keamanan. Lihat pernyataan privasi GitHub untuk detailnya.

6. Hubungi kami

Jika ada pertanyaan, kirim email ke pok.li@icloud.com. Email Anda hanya digunakan untuk membalas Anda. Jika kebijakan ini berubah, kami akan memperbarui halaman ini dan tanggal berlakunya.
