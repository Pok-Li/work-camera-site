เครื่องมือที่ทำงานบนอุปกรณ์ · ไม่เชื่อมต่ออินเทอร์เน็ต

นโยบายความเป็นส่วนตัว

วันที่มีผล: 29 ตุลาคม 2026 · ใช้กับ Work Camera 0.4.0

Work Camera เป็นเครื่องมือที่ทำงานบนอุปกรณ์ของคุณ ไม่เชื่อมต่ออินเทอร์เน็ต ไม่ต้องมีบัญชี และไม่เก็บรวบรวมข้อมูลส่วนบุคคลใด ๆ

1. เราไม่เก็บรวบรวมข้อมูลใด ๆ

แอปไม่มีเซิร์ฟเวอร์ ไม่มีโฆษณา สถิติ หรือฟังก์ชันติดตาม และจะไม่ส่งรูปภาพ วิดีโอ หรือข้อมูลการใช้งานของคุณให้ใคร การถ่าย การนำเข้า การบีบอัด การใส่ลายน้ำ และการจัดการอัลบั้มทั้งหมดทำบนอุปกรณ์ของคุณเท่านั้น

2. การใช้สิทธิ์

  • กล้อง: ถ่ายรูปภาพและวิดีโอ
  • ไมโครโฟน: บันทึกเสียงของวิดีโอ
  • รูปภาพ: บันทึก อ่าน และจัดการรูปภาพและวิดีโอ ต้องได้รับการยืนยันจากคุณก่อนลบต้นฉบับเสมอ

คุณสามารถปิดสิทธิ์ในการตั้งค่าระบบได้ทุกเมื่อ เมื่อปิดแล้วจะใช้ฟังก์ชันที่เกี่ยวข้องไม่ได้

3. ข้อมูลของคุณเก็บไว้ที่ไหน

รูปภาพและวิดีโอเก็บไว้ในคลังรูปภาพของระบบ ส่วนการจัดกลุ่มอัลบั้ม ระยะเวลาเก็บ และการตั้งค่าจะเก็บไว้บนอุปกรณ์นี้เท่านั้น การถอนการติดตั้งแอปจะลบข้อมูลที่บันทึกไว้ในเครื่องเหล่านี้ แต่ไม่ส่งผลต่อรูปภาพและวิดีโอในคลังรูปภาพของระบบ การซิงค์ของระบบ เช่น รูปภาพ iCloud จะเป็นไปตามการตั้งค่าระบบของคุณ

4. การแชร์

ไฟล์ที่เลือกจะถูกส่งให้แอปที่คุณเลือกเฉพาะเมื่อคุณเป็นผู้แชร์ผ่านแผงแชร์ของระบบเท่านั้น หลังจากนั้นแอปดังกล่าวจะเป็นผู้จัดการไฟล์

5. เว็บไซต์นี้

เว็บไซต์นี้เป็นหน้าเว็บแบบสแตติกที่โฮสต์บน GitHub Pages ไม่มีสคริปต์สถิติหรือคุกกี้ GitHub อาจบันทึกที่อยู่ IP ของผู้เยี่ยมชมเพื่อความปลอดภัย ดูรายละเอียดได้ในคำชี้แจงสิทธิ์ส่วนบุคคลของ GitHub
